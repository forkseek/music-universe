# Music World 三分钟演示脚本

录制目标：展示真实可操作的闭环。录制前用全新浏览器会话打开本地或已验收的演示地址，确认服务正在运行。视频中的 Demo 明确标注为编辑样例；当前没有真实模型调用，也没有普通浏览器里的 QQ 授权。[108 秒无配音字幕草稿](artifacts/local-demo-draft.mp4)已在本机录制，可对照本脚本补旁白、重录或剪辑；[16:9 封面草稿](artifacts/cover-draft.png)仅供预览。

| 时间 | 画面与操作 | 建议旁白 |
| --- | --- | --- |
| 0:00–0:20 | 首页标题、四个来源状态 | “歌单分散在不同文件和平台，重复歌曲难整理，喜欢的音乐之间的联系也看不见。Music World 从元数据出发，把它们变成可探索的地图。” |
| 0:20–0:45 | 点击“体验三种格式样例”，展示 9 条记录合并为 3 首；再点击“载入 60 首 Demo · 20 位艺术家 · Try Demo” | “CSV、JSON、TXT 可以一起导入，同一首歌保留多个来源，Live、Remix 仍单独保留。这里使用标明的 Demo 库，让路线有足够歌曲。” |
| 0:45–1:30 | 输入世界名称并生成；展示 30 个主要节点、代表性连线；用“快速定位”选择一个有关系的歌曲或流派，查看卡片依据 | “60 首歌保存在库中，地图只显示有限的主要节点。点击节点能看到歌曲、艺术家、专辑，以及同流派、同专辑或歌单共现等来自导入数据的证据。全图看不清时可以快速定位并放大。” |
| 1:30–2:30 | 在卡片输入“更梦幻一点”；可先用 Guide 查看依据，再生成 5 站 Journey；点击第 2、5 站，展示地图聚焦与橙色路线；打开路线详情并刷新 | “这版先保留模型接口。现在看到的‘更梦幻一点’由基础算法按明确导入的流派标签调整，页面会标出基础路线，不冒充 AI 结果。五站都是真实库内歌曲；模型缺席时依然能保存和继续探索。” |
| 2:30–3:00 | 返回世界或首页，展示已保存世界、来源状态和数据删除入口 | “用户可以导入自己的歌单，也可离线使用 Demo。匿名会话的数据、世界和 Journey 重启后仍在；当前会话的数据可以清空。平台音频留在原平台，产品只处理元数据和探索。” |

录制时优先使用 [首页](artifacts/d6-home.png)、[世界地图与关系卡片](artifacts/d6-world-desktop.png)、[歌曲卡片](artifacts/d6-music-card.png)、[Journey 路线](artifacts/d6-journey-desktop.png) 对照画面。若 Demo 当前选中节点没有来源网页链接，展示“未提供链接”即可；不要点击或声称存在未经验证的平台歌曲页面。真实文件来源链接的单独验收在浏览器测试中覆盖。

操作备用：`npm run dev` 在本机启动，标准无密钥入口是文件和 Demo。演示前先运行 `npm run check` 与 `npm run test:e2e`，再打开页面；如现场网络不可用，已安装依赖且服务运行的本地 Demo 不依赖第三方接口。当前提交表需登录才能核实视频规格；公开演示地址、团队信息仍待填写。草稿为 Playwright 独立匿名会话录制，结束后清理该会话；对应脚本是 `npm run demo:record`，输出 WebM，MP4 是本机用 ffmpeg 转码的预览副本。
