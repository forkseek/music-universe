# D6 本机演示候选与试玩记录

日期：2026-10-03（北京时间）。演示范围按已确定的“先本机演示”执行：正式构建在 `http://127.0.0.1:3000/` 运行，数据库为本机 SQLite 文件。这个地址只对本机开放；尚无可供异地同学访问的公网地址，也未验证 Docker 或云平台的磁盘生命周期。

## 视觉与操作

- 首页直接说明“歌单 → 去重 → 可点击的关系地图 → 五站 Journey”，并在首屏提供上传与 Try Demo 的锚点入口；保留项目规则指定的 `Build My Music World` 核心按钮。
- 少量节点仍自动适配全图；主要节点较多时默认以当前节点为中心，以可读字号展示局部地图。缩放、全图按钮和快速定位仍可使用；手机视野验证当前节点完全在地图内。
- 连接卡片直接显示相邻节点名称与真实关系原因，点击可到下一个节点；先展示 4 条，其余收进展开区。选中状态、路线动画、加载提示和无数据提示均保留。

## 问题排序与范围冻结

先修无法导入、无法保存或无法进入路线的**阻断操作**，再修错误歌曲、错误关系、错误归属或删除不彻底的**结果错误**；其后处理理解困难，最后处理纯视觉细节。本轮内部审查发现并修复：手机当前节点出屏、30 节点总览字太小、关系理由未标明目标节点、Guide 选择框在窄栏错位、首页首屏缺少直达入口。自动化测试未发现仍在复现的阻断项。

本机候选的功能范围从此以修复为主，不再新增 Provider 或模型能力。**真人试玩尚未进行**，因此“新用户 10 秒内理解并独立完成流程”和最终功能冻结仍需填写上表后验收；不要把自动化浏览器测试计作 3–5 位同学的反馈。
