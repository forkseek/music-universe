# D2 验收记录

日期：2026-10-03（北京时间）。D2 的范围是把 D1 导入结果持久保存、建立真实关系数据并为部署准备固定磁盘。

完成：SQLite + Drizzle 自动迁移、外键/WAL/事务；匿名随机 Cookie 的哈希入库与资源隔离；歌曲、艺术家、专辑、来源、显式歌单和导入报告持久保存；文件哈希与来源指纹实现重复导入幂等；当前会话删除；独立的 60 首 / 20 位艺术家 Demo；真实同艺术家、专辑、流派、歌单共现关系与明确偏好权重；世界节点、边、群组、解释依据存库。

验证：三种文件格式合计 9 个来源保存为 3 首歌；重复上传不增加歌曲/来源；数据库重开及独立生产进程重启后仍能读回相同音乐库和世界；两匿名会话隔离；100 首合成测试歌曲只生成不超过 30 个主节点，所有关系引用已有节点和歌曲；数据库 integrity=ok、foreign_key_check=0。错误文件返回中文问题并记录失败，无凭证字段进入白名单数据。

本机单实例 Node.js 方案及数据目录读写已验证；Dockerfile/Compose 提供持久卷配置，但云端和 Docker 重建未实测，需目标环境提供后验收。详细命令见 [README](../README.md) 和 [部署说明](DEPLOYMENT.md)。D2 截图：[桌面关系概览](artifacts/d2-world-desktop.png)、[手机关系概览](artifacts/d2-world-mobile.png)。
