# 公网封面同步与平台连接修复

2026-10-09，发布分支 `codex/netlify-neon`。修复针对网易云公网站点，不修改原来两个本地工程。

## 定位与实现

修复前，真实公网《十年》的专辑接口能返回《黑白灰》、封面和第 4 首位置；界面先更新专辑，再创建空纹理重新加载同一封面，截图中出现暂时黑色的恒星。自动同步的图片预加载与恒星图片加载彼此独立。另一个可复现的状态问题是：正在准备新选择时，旧歌的专辑匹配被暂缓；新选择失败后匹配未重新应用。

- `apps/music-universe/src/lib/albumCover.ts`：将已加载的公共同源平台封面交接给渲染层。缓存最多 2 张图片、60 秒，上传的 blob/data URL 不进共享缓存；单次图片期限 10 秒，最多尝试 2 次，间隔 250 毫秒。失败不缓存，取消的旧请求不能更新缓存。
- `useAlbumTexture.ts`：保持原纹理绑定，待新图片加载、GPU 上传完成后替换；随后释放旧 GPU 纹理。失败状态绑定到对应 URL，避免污染下一张封面。保留球形贴图、接缝融合和色调光照。
- `usePlaybackAlbum.ts` / `App.tsx`：继续监听原生播放器的 `playing`，保留最后播放请求优先校验；播放事件被状态更新取消或匹配被暂缓时，可以重新同步。歌曲封面和对应星球同步更新，保持现有镜头和 Canvas。
- `musicWorldTransport.ts`：网络操作有期限；仅明确的读取操作在 502/503/504 或网络失败时重试一次，间隔 350 毫秒。登录、退出、播放地址解析不自动重复。搜索/状态/歌词期限 15 秒，专辑期限 20 秒，其余默认 30 秒。
- `musicReadCache.ts` / `musicPlatforms.ts`：搜索缓存 2 分钟、状态 15 秒、有效歌词 10 分钟，共最多 32 项。账号连接/登录成功/退出/会话更新时清空；旧账号请求不能重新填入缓存。手动刷新状态绕过缓存。无歌词结果不缓存，不保存音频地址或凭据。
- `integrations/mineradio/netease-network.cjs`：复用现有 SDK 的 Axios 依赖和 Node HTTP/TLS 连接，最多 8 个活动连接、2 个空闲连接，每次上游请求期限 12 秒。仅作用于网易云官方域名，保留代理设置；每个并发调用独立接收取消信号。
- `worker.cjs` / `runtime.ts`：按需加载平台依赖，取消消息可中止网易云上游请求。仅在全部待处理调用结束后释放进程引用，避免取消一个调用影响另一个。
- `src/db/schema.ts` / `shared-state.ts`：短期非敏感限流计数使用 PostgreSQL 单次原子 upsert，替换此前多轮串行事务。新的增量迁移 `0002_secret_naoko.sql` 只添加计数表；账号、播放票据和扫码状态继续加密并按用户隔离。每个用户只有服务端固定动作键，不接收任意客户端键。

## 已验证

- 根工程 ESLint、TypeScript 和 187 项测试通过。前端 148 项测试通过，包含图片失败、取消、图片交接、请求超时、安全重试和缓存隔离。
- Next.js / Vite 正式构建通过；音乐工作进程依赖可实际加载。
- 浏览器 `test:album-cover` 使用自制音频和图片：图片第一次失败后恢复、暂缓匹配在切歌失败后恢复、快速切歌最后请求优先、热缓存恢复、不出现空纹理过渡、真实 GPU 上传、同一个 Canvas 与沉浸模式保留，全部通过。
- 原有自动下一首浏览器测试在本次隔离预览上全部通过，测试音切换约 446 毫秒。此数字不代表第三方音源网络延迟。
- 两个独立正式服务的协议测试通过：扫码状态、目录和播放票据跨实例接续，退出撤销生效，70 秒自制音频原生播放结束，7 次分段均不超过 4 MiB。预设请求计数 94 后发出 10 次并发状态读取，准确允许 6 次、拒绝 4 次，达到共享上限 100。真实工作进程依赖亦通过加载验证。
- 公网修复前真实 API 基线：网易云搜索约 4.9–5.0 秒，专辑约 4.8–5.1 秒，封面约 1.0–1.2 秒；采用一次匿名测试会话，未查看用户账号数据。

公网新版本结果另记录于 `NETLIFY_VALIDATION.md`。真实账号权益、手机扫码确认和平台可用性不能由自生成音频测试代替。没有引入新依赖、虚构账号或绕过平台权限。

## 复验与回滚

在根目录运行 `npm run check`、`npm run build -- --webpack`、`npm run test:cloud-runtime`。星系目录运行 `npm test`；将 `UNIVERSE_TEST_URL` 指向本次预览或 `/universe/index.html`，运行 `npm run test:album-cover` 和 `npm run test:auto-next`。

Windows 沙箱测试若出现 Vite 临时文件访问错误，可把 `TMP`/`TEMP` 指向项目内专用临时目录；原生编译器需要可访问的项目路径。上述是本机测试环境限制，不是平台接口响应。

回滚可重新发布上一可用 Netlify 部署 `6ac869e7c681bf2083902db4`。迁移只增加表，旧代码可继续运行，无需删除用户数据或计数表。
