# 音乐宇宙本机登录助手

音乐搜索现在可以连接电脑上的助手，使用参考项目的登录方式连接四个平台。网站仍由 Netlify 提供页面，平台账号会话由本机助手保存和使用。

## 使用

1. 在安装了 Node.js 24 的 Windows 电脑上，首次下载项目后运行 `npm ci`。
2. 双击项目目录中的 `Start-Music-Helper.cmd`，或在项目目录运行 `npm run music:helper`。保留该进程运行。
3. 打开音乐宇宙网站的「音乐搜索」，点击「连接本机助手」。如果浏览器询问本机网络访问权限，请允许当前音乐宇宙网站访问。
4. 选择音乐平台，点击「连接账号」，本人完成官方登录和手机确认。

| 平台 | 登录方式 |
| --- | --- |
| QQ 音乐 | 独立 QQ 音乐官方窗口，完成登录后读取账号资料 |
| 网易云音乐 | 网站显示二维码，网易云音乐 App 扫码确认 |
| 酷狗音乐 | 独立酷狗官方窗口，完成平台登录 |
| 汽水音乐 | 网站显示二维码，用抖音 App 扫码；需要二次验证时打开官方窗口 |

点击「取消登录」会终止该次登录；「退出」删除所选平台的本地账号记录；「断开助手」撤销当前页面的助手连接，已保存的账号仍在电脑上。重新打开助手并连接网站后可以恢复账号状态，平台会话过期时需要再次登录。登录本身不增加平台的播放或会员权限，当前 QQ 音乐播放适配仍保持原有权限限制。

## 数据和连接

- 仅监听 `127.0.0.1:43891`，默认只允许正式 Netlify 域名及列出的本地开发地址。额外站点通过 `MUSIC_HELPER_ALLOWED_ORIGINS` 明确配置。
- 平台会话经 AES-256-GCM 加密保存在 `data/music-helper/accounts.db`，本地密钥和站点会话映射同目录保存。不要上传或分享该目录。
- 浏览器持有的是可撤销、按网站来源隔离的助手连接凭据，保存在当前标签页的 `sessionStorage`。平台 Cookie、密码、密钥不会进入网页响应或 Netlify。
- 音频和封面使用单独的只读凭据；它不能调用登录、退出或账号接口。生产页面 CSP 仅增加固定助手地址。
- 本机助手需要独立运行；部署 Netlify 网站不会在访客电脑上自动安装或启动 Electron。

## 参考源码与验证范围

用户提供的 `Mineradio_3-5-8.zip` 只有前端。其登录流程文件与项目中既有 Mineradio 参考源码一致，因此继续使用 `integrations/mineradio` 中已保留许可及来源的适配组件，完善 QQ 官方窗口和汽水二维码状态处理。

`integrations/mineradio/universe-helper.patch` 保留外部音乐宇宙 Vite 源码的变更；发布资源同步至 `public/universe`。对原 Vite 源码应用该补丁后，设置 `MUSIC_UNIVERSE_SOURCE` 并运行 `npm run build:universe` 可重新构建。

验证记录见 `docs/artifacts/music-helper-20261009`。真实上游验证覆盖四个平台登录入口、两种二维码和取消；账号确认、个人歌单及会员权益需要使用者本人完成授权后再验证。自动化成功登录、加密存储、取消后拒绝回写和不同用户隔离使用测试样例验证，不代表真实账号已登录。
