## 安全检查与修正

### 浏览器防护

此前页面缺少主要安全响应头，本次补充：

- 每次页面请求生成独立随机 nonce；生产脚本策略使用 strict-dynamic，不开放脚本的 unsafe-inline 或 unsafe-eval。
- 禁止插件对象、跨站表单目标和默认外站嵌入，限制资源来源。
- 设置 nosniff、Referrer-Policy、Permissions-Policy 和 X-Frame-Options。
- HTML 按请求渲染且不缓存，保证策略与框架脚本 nonce 一致。媒体帧不经过 nonce 处理。
- 调整 Zod 为 jitless 模式，避免其动态编译探测触发严格策略。校验规则保持一致。

Motion 和 React Flow 需要内联样式计算位置，因此样式策略保留 unsafe-inline；脚本策略没有该权限。防护设计参考 [OWASP HTTP 响应头建议](https://cheatsheetseries.owasp.org/cheatsheets/HTTP_Headers_Cheat_Sheet.html)。

默认禁止外站嵌入。若以后接入获准的官方 H5 宿主，可通过 APP_FRAME_ANCESTORS 配置明确的 HTTPS 父级来源；通配域名、HTTP、路径和用户密码形式均被拒绝。修改后需要重新构建和重启。

### 接口与数据

实际请求已验证：

- 缺少写入标记、伪造 Origin 或跨站写入返回 403。
- 会话 A 无法读取或使用会话 B 的世界、旅程和向导数据，返回 404。用户归属来自服务器会话，不能通过提交 userId 覆盖。
- Cookie 具有 HttpOnly、SameSite=Lax；HTTPS 配置下启用 Secure。会话 token 哈希保存在数据库，接口响应不缓存个人数据。
- 非法 JSON、非法字段和空曲库返回相应错误；超限请求和超限文件返回 413。
- 文件大小限制为每个 2 MiB、合计 10 MiB、最多 10 个；流式读取在达到限制后停止。
- 上传 HTML 标签以普通文本显示，未执行事件脚本。危险链接、音频地址和凭据字段被丢弃。
- 来源链接只保留允许的 HTTPS 歌曲网页，外部网页链接使用 noopener noreferrer。未发现用上传字段执行 SQL、HTML 或脚本的路径。

来源限制符合当前项目的数据边界。跨站写入防护参考 [OWASP CSRF 建议](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。

### 依赖审计：仍有一个开发工具问题

运行依赖审计结果：**0 个已知漏洞**。

包含开发工具的完整审计仍报告 **5 项高危告警，来自同一条依赖链**：

eslint-config-next → @next/eslint-plugin-next → fast-glob → micromatch → braces。

根问题是 CVE-2026-93687 / GHSA-vfj7-8cjw-p6xm，涉及深层嵌套模式导致栈耗尽。检查时 braces 3.0.3 仍无已发布修补版本；这是待处理项，不能称为已经修复。[官方漏洞公告](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)。

该链用于开发阶段的 ESLint 文件查找，本次未发现它进入用户上传处理或线上请求路径。未采用审计工具建议的框架配置降级；后续应随官方补丁升级开发依赖。
