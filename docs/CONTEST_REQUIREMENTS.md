# 腾讯音乐首届高校 AI Hackathon：公开规则核对

核对日期：2026-10-03。来源为[腾讯音乐赛事官网](https://join.tencentmusic.com/ai-hackathon/)；正文实际嵌在官网同域的 H5 页面。报名、提交表和赛题包需要登录，以下只记录公开可核实内容，不猜测表单必填状态。

| 项目 | 官网公开内容 | 对 Music World 的处理 |
| --- | --- | --- |
| 赛道 | “TME 产品创新功能”或“创新音乐产品”，二选一；网页、App、小程序等载体均可 | 当前独立网页更符合“创新音乐产品”；最终由报名人选择 |
| 截止 | 报名与初赛作品提交均须在 **2026-10-09 23:59 前**完成 | 演示材料与可访问性至少提前一天完成；不要等最后一分钟 |
| 资格 | 在校学生，单人或 1–2 人团队；每人仅一队，每队一份作品 | 需由参赛者确认在校身份和队伍成员；团队赛由队长填报 |
| 初赛材料 | 产品方案简介，包含问题洞察、解决方案、Demo 等；投稿流程还列出姓名/分工、作品名称/赛道、简介/创作思路，以及 Demo 链接、演示视频、封面图等作品资料 | 已准备作品说明草稿、脚本、截图、无配音录屏与封面草稿；正式视频规格、外部可访问 Demo 链接待确认 |
| 评审 | 用户价值、可行性、创新性 | 说明与视频分别展示真实需求、完整可运行链路、音乐关系地图的新体验 |
| 决赛 | 入围后另交成功部署上线的完整产品方案与路演 PPT；页面标注决赛材料 2026-11-02 23:59 截止 | 与初赛要求分开，当前先确保初赛完整 |
| 原创与许可 | 作品需原创；公开规则要求如实披露第三方开源框架、代码及对应协议 | 已生成[开源依赖记录](OPEN_SOURCE_NOTICE.md)与[完整锁文件清单](THIRD_PARTY_LICENSES.csv)，仍需审查后续素材 |

公开页面另列有获奖后著作财产权归属、未获奖作品权利与赛事宣传使用授权等条款。报名和提交前，队伍成员应阅读[官网规则原文](https://join.tencentmusic.com/ai-hackathon/)并自行确认接受，尤其在多人组队时。

官网提供的[报名入口](https://doc.weixin.qq.com/forms/AJEAIQdfAAoAMcA1QYhACoCNM0LaWBSgf)、[作品提交入口](https://doc.weixin.qq.com/forms/AJEAIQdfAAoAMcA1QYhACoCNc1YDZZthf)和[官方赛题包](https://saas.docs.qq.com/sheet/DR2VHa0JGT3ZGVFNKTmpybUdJ?tab=000001)已定位，但未登录时分别跳转企业微信文档或腾讯文档登录页，无法验证字段字数、附件格式与大小、Demo 链接是否必填、报名或提交是否已成功。**本机的 `127.0.0.1` 仅供本人演示，评委无法通过它打开 Demo**；若提交表要求可访问链接，需提供已验证的公开演示地址或按表单允许的方式提交视频。当前没有替用户报名或提交。
