# Music World 每日执行清单

计划日期：2026-10-02 至 2026-10-09，使用北京时间。

依据：`PROJECT_RULES.md` 与 `IMPLEMENTATION_PLAN.md`。这是对既有计划的任务拆分，不替代最新项目规则。

## 使用方式

- 按一条主开发线安排；代码、测试和技术文档由开发侧执行，产品选择、人工试玩和赛事材料由产品侧配合，同一人可以兼任。
- 每天分成三个工作段，表示完成顺序，不要求固定上午、下午或晚上。今天剩余时间不足时，优先完成当日第一工作段，再滚动更新进度。
- 只有实际实现并通过对应检查后才能勾选完成。D1–D3 已完成本机验收；D4 的接口、回退和 D5 的事实 Guide、QQ 适配层已完成本机及替身测试。真实模型、真实 QQ 授权和线上部署单独待验收，证据见 [D4](D4_AI_INTERFACE_ACCEPTANCE.md)、[D5](D5_GUIDE_QQMUSIC_ACCEPTANCE.md)。
- 保留严格顺序：Provider → File → 标准化 → 去重 → 数据库 → Graph → World UI → Journey → AI Guide → QQ 官方适配 → UI 打磨。
- 当天完成后可以提前推进次日工作；未通过关键验收时，先修复依赖问题，再做后续功能。
- 日期是开发目标；赛事官网已核实报名与初赛提交截止为 2026-10-09 23:59，详见[公开规则核对](CONTEST_REQUIREMENTS.md)。实际表单字段仍需参赛者登录后检查；官方接入权限和云端部署条件单独验收。
