# Music World 连续场景与互动大厅

## 当前连续动画

当前时间线使用用户提供的 music_world_3shots_60fps_final.mp4，包含音乐光网、机器人奔跑、跳跃到大厅三段画面。该素材已是 60 fps，网页保留其画面与时序，没有重新拼接或补帧。

| 项目 | 当前值 |
| --- | --- |
| 画面 | 1344 × 768，原始 7:4 比例 |
| 帧率和帧数 | 60 fps，801 帧 |
| 时间线末端 | 13.333333 秒，以 timeline.json 为准 |
| MP4 | music-world-continuous.mp4，14,345,417 字节，约 13.7 MiB |
| 帧序列 | frame-00000.webp 至 frame-00800.webp，合计 82,439,334 字节 |

页面优先解码当前位置附近的 WebP 帧，限制缓存窗口；无法逐帧绘制时回退到同一条 MP4。原始三段动画和旧的派生素材保留。

## 滚轮与分层入口

- 下滑前进，上滑回退；三段之间没有其他界面。
- 完整行程约 6,600 像素，单次事件上限 180 像素，0.105 秒阻尼；限制推进速度及积压。
- 手机通过上滑和下滑控制动画。大厅可左右平移；横屏容纳全部七个入口。
- 自动漫游连续观看；进入大厅可跳至结尾。重新唤醒回到开场，上滑可返回动画。
- 新打开首页从动画开始；直接访问 #hall、从模块返回或减少动画偏好时展示大厅。
- 鼠标悬停或键盘聚焦图标，显示毛玻璃云朵说明。Esc 关闭；点击图标用云雾进入模块。

## 2K 停留画面

scene-hall.webp 保留原动画最后一帧。scene-hall-2k.webp 是 2688 × 1536 的高清停留板，488,026 字节：以最后一帧为参考，用内置 imagegen 增强细节，再用 Lanczos3 导出为目标尺寸。生成源图实际为 1659 × 948；本素材是增强及放大后的 2K 资源，原视频仍为 1344 × 768。

高清板解码完成后约 1.45 秒渐入，载入期间保留原画面。渲染尺寸按屏幕和像素比例适配，上限 2688 × 1536。

- 机器人手约 1.4 度轻摆，周期约 5.1 秒，局部变形避免手部切片和重影。
- 头灯约 5.6 秒缓慢闪烁；图标、光点、眼睛、胸灯和地面光环缓慢呼吸。亮区整体变化控制在约 1.2%。
- 动态画面限制为约 30 fps，保持动作细小；标签页隐藏或离开大厅时暂停，离开时释放 GPU 资源。
- WebGL 不可用时保留 2K 静态画面与 CSS 灯效。减少动画偏好时停止手部和呼吸动画。

生成原图及完整提示词保存在 docs/artifacts/hall-enhanced-source.png 与 docs/artifacts/hall-2k-generation.json。

## 场景与功能

音符 → 音乐地图；唱片 → 我的曲库；话筒 → 文件导入；吉他 → Demo；爱心 → 保存的旅程；钢琴 → 音乐向导；耳机 → 官方连接状态。

各模块背景继续使用动画中的场景素材：导入和地图使用 scene-awaken.webp，Demo 使用 scene-run.webp，Journey 使用 scene-light.webp，曲库等使用结尾场景。模块进出保留云雾过渡。

## 素材维护

timeline.json 和当前用户提供的 60 fps 成片是当前版本的依据。scripts/prepare-continuous-animation.mjs 是旧的 24 fps 三片拼接工具；它的输出规格与当前成片不同，不用于当前素材更新。
